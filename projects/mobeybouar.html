MobeybouAR

Tech: Unity, ARFoundation with ARCore Extensions

MobeybouAR was created for project Mobeybou-OUT. It is a mobile application that enables users to create and record markerless AR stories, by manipulating characters and objects in real-world environments.

Key features:

  • Records AR scenes by combining virtual elements with live camera input and microphone audio
  • Supports positioning and animating story elements
  • Implements weather effects through particle systems and environmental overlays
  • Uses plane detection to place 3D landscapes on surfaces

A previous version also included Firebase integration for storing and sharing stories across devices.
